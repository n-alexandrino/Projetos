## 📌 Sobre o projeto

Este projeto foi desenvolvido em Python para uma atividade de Desenvolvimento de Sistemas. O programa classifica o consumo mensal de água de um imóvel e mostra uma mensagem de acordo com o tipo de imóvel e a quantidade de água consumida.

O objetivo é ajudar na conscientização sobre o uso da água e alertar quando o consumo estiver acima do padrão residencial.

## 🐍 Linguagem utilizada

- Python

## ⚙️ Como funciona

O programa solicita:

- o tipo de imóvel: `comercial`, `casa` ou `apartamento`;
- o consumo mensal de água em metros cúbicos (m³).

Depois, o programa analisa as informações e mostra uma mensagem indicando se o consumo é econômico, moderado, excessivo ou se deve ser aplicada a tarifa comercial.

## ▶️ Como executar

1. Tenha o Python instalado.
2. Abra a pasta `consumo-agua`.
3. Execute o arquivo:

```bash
python app.py
```

4. Digite o tipo de imóvel e o consumo mensal quando o programa solicitar.

## 💧 Classificações

- Imóvel comercial: informa sobre a tarifa comercial.
- Apartamento com menos de 10 m³: consumo econômico.
- Apartamento ou casa dentro do limite residencial: consumo moderado.
- Consumo acima do limite: consumo excessivo e alerta para economia e vazamentos.

## 🌱 Objetivo

Incentivar o consumo consciente de água por meio de um programa simples desenvolvido com os conceitos de programação estruturada em Python.
