## ✦ SOBRE O PROJETO

Este projeto foi desenvolvido como atividade do curso de **Desenvolvimento de Sistemas**.

O objetivo é criar um programa em Python para realizar uma pesquisa de opinião da empresa fictícia **TudoWeb**, registrando a avaliação dos clientes sobre o atendimento recebido.

---

## ✦ PESQUISA

Cada entrevistado informa:

`NOME` • `IDADE` • `OPINIÃO`

As opções disponíveis são:

> **1 — EXCELENTE**  
> **2 — BOM**  
> **3 — RUIM**

A pesquisa deve ser realizada com **50 entrevistados**.

Ao final, o programa informa a quantidade de avaliações **EXCELENTE** e **RUIM**.
