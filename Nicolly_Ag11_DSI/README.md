# Agenda 11 - Controle de Níveis de Água

Atividade de Desenvolvimento de Sistemas I.

O programa mostra os 5 níveis de água de um reservatório. Cada nível aparece com uma cor diferente no terminal, usando a biblioteca colorama.

## Como rodar

Instalar a biblioteca:

```
pip install colorama
```

Depois executar:

```
python main.py
```

As cores são: vermelho para muito baixo, amarelo para baixo, verde para médio, ciano para alto e azul para muito alto.
