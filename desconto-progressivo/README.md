# Sistema de Desconto Progressivo

Programa desenvolvido em Python para calcular descontos de uma loja online.

## Regras

- Compras abaixo de R$ 200: 5% de desconto
- Compras de R$ 200 até R$ 299,99: 10% de desconto
- Compras a partir de R$ 300: 15% de desconto

## Como executar

Execute o arquivo:

python app.py

Depois, informe o valor total da compra.
